# Деплой TransGUI (Windows)

Деплой выполняет только субагент `transgui-deploy`; main-сессия не копирует файлы
сама. Прочитай `AGENTS.md` (раздел TransGUI deployment).

## Источник и цели

- Источник: `units\transgui.exe` + `units\lang\` (29 файлов).
- Цели: `C:\Program Files\Transmission Remote GUI`,
  `\\samsung-pc\c$\Program Files\Transmission Remote GUI`.
- Задеплой **все переданные цели за один запуск**. Если цели не переданы —
  уточни и подтверди.
- Иконки встроены в exe: папку `icons\` **не копировать**.

## Порядок (для каждой цели)

1. Сравни SHA-256 `transgui.exe` и файлы `lang\*` с целью. Если всё совпадает —
   пропусти цель полностью (без копирования и backup).
2. Перед копированием проверь `Get-Process transgui`. Если процесс запущен — **не
   убивай**: переименуй занятый exe в `transgui.exe.<timestamp>` и скопируй новый.
   Перезапуск — за пользователем. Закрывай приложение только если переименовать
   не удалось.
3. Скопируй `units\transgui.exe` и `units\lang\*` в цель.
4. Проверь SHA-256 источника и установленного exe, сравни lang-файлы.
5. Удали старые `transgui.exe.YYYYMMDD-HHMMSS`; заблокированные оставь до перезапуска.
   Не удаляй по маске `transgui.exe.*` без проверки, чтобы не задеть сам exe.
6. Не запускай приложение без просьбы.

## Ошибки доступа

- Сначала попробуй доступ как есть. Если `C:\Program Files` или шаг требуют прав —
  подготовь готовую elevated-команду (`Start-Process ... -Verb RunAs`) и попроси
  пользователя запустить; без согласия elevated не запускай.
- Если `\\samsung-pc\c$` недоступен — аутентифицируйся
  (`net use \\samsung-pc\c$` с учёткой из `_netrc`, machine `samsung-pc`) и повтори;
  иначе сообщи и пропусти цель.

## Отчёт

Что остановлено, что скопировано, что проверено, какие backup остались.
